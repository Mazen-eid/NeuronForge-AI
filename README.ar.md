# NeuronForge AI — النسخة العربية

**فريموورك مفتوح المصدر لتشغيل قنوات يوتيوب أوتوماتيك بشكل واقعي.**
يكتشف الترندات → يكتب السكريبت بنموذج ذكاء اصطناعي → يعمل صوت مجاني (Edge TTS) → يجمّع الفيديو بـ FFmpeg → يرفعه على يوتيوب حسب جدول زمني.

---

## إيه اللي المشروع ده بيعمله — وإيه اللي مش بيعمله

**بيعمل:**
- Pipeline شغال فعلاً: `ترند → سكريبت → صوت → فيديو → رفع`.
- Modular: تقدر تبدّل أي مرحلة (نموذج AI مختلف، TTS مختلف، مصدر ترندات مختلف).
- يشتغل حتى بدون أي مفاتيح API: هيولدلك فيديو تجريبي (MP4) في وضع الـ dry-run.

**مش بيعمل:**
- دخل تلقائي من الصفر بدون أي تدخل منك. أنت محتاج:
  - قناة يوتيوب خاصة بيك (مجانية).
  - مشروع على Google Cloud + OAuth credentials للرفع (المجاني يكفي لـ ~6 فيديو/اليوم/القناة).
  - اختياري: مفتاح Groq مجاني للـ LLM، أو مفتاح OpenAI مدفوع.
- بديل عن الإشراف البشري. القنوات اللي بتنشر محتوى AI بدون مراجعة أسرع طريقة للإغلاق من يوتيوب. **راجع كل فيديو قبل نشره للعام.**

### جدول التكاليف الحقيقي (قناة واحدة، ~3 فيديوهات/اليوم)

| الخدمة | الـ free tier كافي؟ | ملاحظات |
|---|---|---|
| LLM (Groq) | ✅ | 14,400 طلب/اليوم مجاني حالياً |
| LLM (OpenAI gpt-4o-mini) | ❌ مدفوع | حوالي 0.5-2 دولار/الشهر على الحجم ده |
| TTS (Edge) | ✅ | صوت مايكروسوفت مجاني |
| صور ومقاطع (Pexels/Pixabay) | ✅ | مفاتيح مجانية بدون بطاقة بنكية |
| رفع على يوتيوب | ✅ | الحصة المجانية 10,000 وحدة/اليوم، الفيديو ~1,600 |
| كمبيوتر/سيرفر | ✅ | أي لابتوب يكفي، مش محتاج GPU |

## الخطوات السريعة

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

# تشغيل تجريبي بدون أي مفاتيح — هيطلعلك فيديو في data/runs/<id>/video.mp4
neuronforge run example-ar-tech --dry-run

# تشغيل لوحة التحكم
neuronforge api
# في تيرمنال تاني: python -m http.server -d frontend 5173
# افتح http://localhost:5173
```

### عشان ترفع فعلاً على يوتيوب

1. اعمل ملف YAML لقناتك تحت `backend/channels/<اسم-القناة>.yaml` (انسخ واحد من الأمثلة).
2. مفتاح Groq مجاني: <https://console.groq.com/keys>. حطه في `backend/.env` كـ `GROQ_API_KEY=…` وعدّل `LLM_PROVIDER=groq`.
3. إعداد رفع يوتيوب (مرة واحدة، مجاني):
   - <https://console.cloud.google.com/> → مشروع جديد → فعّل **YouTube Data API v3**.
   - **OAuth consent screen** → External → Testing → ضيف الجيميل بتاعك كـ test user.
   - **Credentials** → OAuth client ID → Desktop app → نزّل الـ JSON.
   - احفظه في `backend/secrets/youtube_client_secret.json`.
   - شغّل `neuronforge youtube-auth <channel_id>` مرة واحدة لكل قناة — هيفتح المتصفح.
4. شغّل: `neuronforge run <channel_id> --upload`.
5. جدوله: `neuronforge schedule` (هيستخدم حقل `cron:` من كل ملف YAML).

## تنبيه

- **تيك توك** مفيش عنده API رسمي للرفع من الأفراد، فالأداة مش بترفع عليه. ارفع يدوياً من `data/runs/<id>/video.mp4`.
- **دايماً ابدأ القناة** بـ `privacy: private` وراجع الفيديوهات قبل ما تخليها `public`.
- يوتيوب بيحذف بسرعة القنوات اللي بتنشر محتوى AI متكرر بدون إشراف.
